## 1. 프로젝트 개요

### 1.1 프로젝트 배경

IT 학원의 교육 과정 홍보와 수강생 모집을 위한 실전 데모 웹사이트가 필요합니다. 본 프로젝트는 **6개월 자바 풀스택 과정을 수료하면 이런 수준의 웹사이트를 개발할 수 있다**는 것을 실질적으로 보여주기 위한 포트폴리오 프로젝트입니다.

### 1.2 프로젝트 목적

- IT 교육 플랫폼의 핵심 기능을 구현한 풀스택 웹 애플리케이션 개발
- Spring Boot 기반의 3계층 아키텍처를 적용한 실무형 프로젝트
- 온라인 강의 플랫폼 + 커뮤니티 기능을 통합한 종합 교육 시스템 구축
- 실전 포트폴리오로 활용 가능한 완성도 높은 웹 애플리케이션 개발

### 1.3 프로젝트 개요

**CBJF**는 온라인 IT 교육 플랫폼으로, 강의 관리, 수강 신청, 결제, 커뮤니티 등 실제 교육 플랫폼에서 필요한 모든 핵심 기능을 포함하고 있습니다. Spring Boot와 Thymeleaf를 활용한 풀스택 웹 애플리케이션으로 개발되었습니다.

## 2. 프로젝트 목표

### 2.1 비즈니스 목표

1. **학원 홍보**: IT 교육 과정의 품질과 수료 후 역량을 시각적으로 증명
2. **수강생 유치**: 실제 작동하는 플랫폼을 통한 신뢰도 향상
3. **교육 효과 검증**: 6개월 과정의 교육 성과를 실물로 입증

### 2.2 기술적 목표

1. **풀스택 개발 역량**: Backend + Frontend + Database 전 영역 구현
2. **실무 아키텍처**: Spring Boot 3계층 아키텍처 적용
3. **데이터베이스 설계**: JPA를 활용한 엔티티 설계 및 관계 매핑
4. **사용자 경험**: 반응형 웹 디자인 및 직관적인 UI/UX
5. **확장 가능성**: 추가 기능 개발이 용이한 구조 설계

### 2.3 학습 목표

1. **Spring Boot 마스터**: 실전 프로젝트를 통한 프레임워크 숙달
2. **JPA/Hibernate**: ORM 활용 및 복잡한 쿼리 작성
3. **웹 개발 전반**: RESTful API, 템플릿 엔진, 웹 디자인
4. **프로젝트 관리**: Git, Maven, 협업 도구 활용

## 3. 프로젝트 범위

### 3.1 포함 범위 (In Scope)

#### 3.1.1 주요 기능
- ✅ 메인 페이지 (통계, 인기 강의, 최신 강의, 공지사항)
- ✅ 강의 관리 시스템 (목록, 검색, 필터링, 상세 정보)
- ✅ 장바구니 및 결제 프로세스 (데모)
- ✅ 커뮤니티 게시판 (공지사항, Q&A, 자유게시판, 스터디)
- ✅ 마이페이지 (내 강의, 진도율, 주문 내역, 포인트)
- ✅ 수강 후기 및 평점 시스템
- ✅ 댓글 및 소셜 기능 (좋아요, 조회수)

#### 3.1.2 기술 구현
- ✅ Spring Boot 3.2.0 기반 Backend
- ✅ JPA/Hibernate ORM
- ✅ Thymeleaf 템플릿 엔진
- ✅ MySQL 데이터베이스
- ✅ Bootstrap 5.3 UI 프레임워크
- ✅ Maven 빌드 시스템

### 3.2 제외 범위 (Out of Scope)

현재 버전(1.0.0)에서는 다음 기능을 포함하지 않으며, 향후 버전에서 추가 예정:

- ❌ Spring Security 인증/인가 (향후 추가)
- ❌ 실제 결제 게이트웨이 연동 (PG사 연동)
- ❌ 파일 업로드 및 스토리지 (강의 자료, 동영상)
- ❌ 이메일 알림 시스템
- ❌ 관리자 페이지 (CMS)
- ❌ REST API 문서화 (Swagger/OpenAPI)
- ❌ 단위/통합 테스트 코드
- ❌ React/Vue 프론트엔드 분리


### 5.2 3계층 아키텍처 (3-Tier Architecture)

#### Layer 1: Presentation (프레젠테이션 계층)
- **역할**: 사용자 인터페이스 렌더링 및 HTTP 요청/응답 처리
- **기술**: Thymeleaf, Bootstrap, HTML/CSS/JavaScript
- **컴포넌트**: Templates, Fragments, Static Resources

#### Layer 2: Business Logic (비즈니스 로직 계층)
- **역할**: 핵심 비즈니스 규칙 및 데이터 처리 로직
- **기술**: Spring Boot, Java 17
- **컴포넌트**: Controllers (7개), Services (7개)

#### Layer 3: Data Access (데이터 접근 계층)
- **역할**: 데이터베이스 CRUD 작업 및 영속성 관리
- **기술**: Spring Data JPA, Hibernate
- **컴포넌트**: Repositories (11개), Entities (11개)

## 6. 주요 기능 명세

### 6.1 메인 페이지 (Home)

#### 기능 상세
- **Hero Section**: 학원 소개 및 CTA(Call-to-Action) 버튼
- **통계 정보**: 수강생 수, 강의 수, 평균 평점, 취업률 등
- **인기 강의**: 평점 높은 강의 Top 6 표시
- **최신 강의**: 최근 등록된 강의 Top 6 표시
- **공지사항**: 최근 공지사항 3개 표시

#### API Endpoint
- `GET /` - 메인 페이지 렌더링

#### 관련 컴포넌트
- Controller: `HomeController`
- Service: `CourseService`, `PostService`
- Template: `index.html`

---

### 6.2 강의 관리 (Course Management)

#### 6.2.1 강의 목록
- **페이징**: 페이지당 12개 강의 표시
- **정렬**: 최신순, 인기순, 평점순, 가격순
- **필터링**: 카테고리별 (Java, Spring, Frontend, Database, DevOps)
- **검색**: 강의명, 강사명으로 검색

#### 6.2.2 강의 상세
- **기본 정보**: 제목, 설명, 썸네일, 가격, 기간, 난이도
- **강사 정보**: 강사명, 프로필, 경력
- **수강 통계**: 수강생 수, 평균 평점
- **수강 후기**: 후기 목록 및 평점 (1-5점)
- **장바구니 담기**: 강의 장바구니 추가 기능

#### API Endpoints
- `GET /courses` - 강의 목록
- `GET /courses/{id}` - 강의 상세
- `GET /courses/search` - 강의 검색

#### 관련 컴포넌트
- Controller: `CourseController`
- Service: `CourseService`, `CategoryService`
- Repository: `CourseRepository`, `CategoryRepository`
- Entity: `Course`, `Category`, `Review`

---

### 6.3 장바구니 & 결제 (Cart & Checkout)

#### 6.3.1 장바구니
- **담기**: 강의 상세에서 장바구니 추가
- **조회**: 내 장바구니 목록
- **삭제**: 장바구니 항목 제거
- **총액 계산**: 담긴 강의의 총 금액 계산

#### 6.3.2 결제 프로세스 (데모)
- **주문 요약**: 주문 항목 및 총액 확인
- **결제 정보**: 결제 방법 선택 (데모)
- **주문 완료**: 주문 생성 및 수강 등록

#### API Endpoints
- `POST /cart/add/{courseId}` - 장바구니 추가
- `GET /cart` - 장바구니 조회
- `DELETE /cart/{itemId}` - 장바구니 삭제
- `GET /cart/checkout` - 결제 페이지
- `POST /cart/checkout` - 결제 처리

#### 관련 컴포넌트
- Controller: `CartController`
- Service: `CartService`, `OrderService`, `EnrollmentService`
- Repository: `CartItemRepository`, `OrderRepository`, `EnrollmentRepository`
- Entity: `CartItem`, `Order`, `OrderItem`, `Enrollment`

### 6.4 커뮤니티 (Community)

#### 6.4.1 게시판 종류
- **공지사항 (NOTICE)**: 학원 공지사항
- **Q&A**: 질문과 답변
- **자유게시판 (FREE)**: 자유로운 소통
- **스터디 (STUDY)**: 스터디 모집 및 정보 공유

#### 6.4.2 게시판 기능
- **목록 조회**: 페이징 및 검색
- **게시글 작성**: 제목, 내용 작성
- **게시글 상세**: 조회수 증가, 좋아요
- **댓글**: 댓글 작성, 조회
- **검색**: 제목, 내용, 작성자로 검색

#### API Endpoints
- `GET /community/{boardType}` - 게시판 목록
- `GET /community/post/{id}` - 게시글 상세
- `POST /community/post/write` - 게시글 작성
- `POST /community/post/{id}/comment` - 댓글 작성
- `POST /community/post/{id}/like` - 좋아요

#### 관련 컴포넌트
- Controller: `PostController`
- Service: `PostService`
- Repository: `PostRepository`, `CommentRepository`
- Entity: `Post`, `Comment`

### 6.5 마이페이지 (My Page)

#### 6.5.1 내 수강 강의
- **수강 목록**: 내가 등록한 강의 목록
- **진도율**: 각 강의별 학습 진도율 (0-100%)
- **강의 평가**: 수강 후기 작성 가능

#### 6.5.2 주문 내역
- **주문 목록**: 과거 주문 내역 조회
- **주문 상세**: 주문 항목 및 금액 확인

#### 6.5.3 내 정보
- **사용자 정보**: 이름, 이메일, 역할
- **포인트**: 보유 포인트 확인
- **통계**: 총 수강 강의 수

#### API Endpoints
- `GET /mypage` - 마이페이지 대시보드
- `GET /mypage/courses` - 내 강의
- `GET /mypage/orders` - 주문 내역
- `POST /mypage/courses/{id}/progress` - 진도율 업데이트

#### 관련 컴포넌트
- Controller: `MyPageController`
- Service: `EnrollmentService`, `OrderService`, `UserService`
- Repository: `EnrollmentRepository`, `OrderRepository`, `UserRepository`
- Entity: `Enrollment`, `Order`, `User`

#### 7.1.2 주요 관계 (Relationships)

```
User (1) ─────< (N) Course          # 강사 - 강의

User (1) ─────< (N) Order           # 사용자 - 주문

User (1) ─────< (N) Comment         # 사용자 - 댓글

Category (1) ─< (N) Course          # 카테고리 - 강의

Course (1) ───< (N) CartItem        # 강의 - 장바구니
Course (1) ───< (N) OrderItem       # 강의 - 주문항목
Course (1) ───< (N) Enrollment      # 강의 - 수강
Course (1) ───< (N) Review          # 강의 - 후기

Order (1) ────< (N) OrderItem       # 주문 - 주문항목

Post (1) ─────< (N) Comment         # 게시글 - 댓글
```

### 7.2 주요 테이블 스키마

#### 7.2.1 users 테이블
```sql
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    role VARCHAR(20) NOT NULL,  -- STUDENT, INSTRUCTOR, ADMIN
    points INT DEFAULT 0,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);
```

#### 7.2.2 courses 테이블
```sql
CREATE TABLE courses (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    price DECIMAL(10,2) NOT NULL,
    duration_weeks INT,
    difficulty VARCHAR(20),  -- BEGINNER, INTERMEDIATE, ADVANCED
    thumbnail_url VARCHAR(500),
    instructor_id BIGINT,
    category_id BIGINT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    FOREIGN KEY (instructor_id) REFERENCES users(id),
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

#### 7.2.3 enrollments 테이블
```sql
CREATE TABLE enrollments (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    course_id BIGINT NOT NULL,
    progress INT DEFAULT 0,  -- 0-100
    enrolled_at TIMESTAMP,
    completed_at TIMESTAMP,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (course_id) REFERENCES courses(id)
);
```
